# Tools removed from every Claude Code session of this agent: install.sh writes them to
# permissions.deny in ~/.claude/settings.json. A bare tool name removes the tool's
# definition from every request, the main session's and its subagents', and from the
# owner's direct session too. One name per line.
#
# Two groups:
#   1. Every Slack MCP write tool. The Slack connection acts AS THE OWNER, so a write
#      would post in their name. This group is generated from the `write` lines of
#      slack-tools.txt and must stay identical to them (test_slack_readonly.sh).
#      guard.sh refuses any unclassified mcp__slack__* call on top of this list.
#   2. Tools no procedure of this definition calls, so their definitions leave every
#      request (test_harness.sh fails when CLAUDE.md, ONBOARDING.md, README.md or docs/
#      names one of them).
#
# The platform's own prompts call tools too, and these stay available: onboarding
# calls set_onboarding_checklist, complete_onboarding_step and mark_onboarding_complete;
# a Kit Update calls list_schedules, create_schedule, report_kit_updated and
# cancel_kit_update (test_harness.sh fails when one of them is listed here).
